# npx + stdio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Chạy MCP bằng `npx -y lta-redmine-mcp` qua stdio (mặc định), vẫn giữ chế độ HTTP bằng `--http` / `MCP_TRANSPORT=http`.

**Architecture:** `parseConfig` quyết định transport. Vòng đăng ký tool tách ra `createMcpServer(gw, apiKey)`, dùng chung cho `McpController` (HTTP) và `main.ts` (stdio, `NestFactory.createApplicationContext` không có Express). Gateway không đổi.

**Tech Stack:** Node ≥ 22.9, NestJS 11, `@modelcontextprotocol/sdk` 1.x (`StdioServerTransport`, `StdioClientTransport`, `InMemoryTransport`), Jest.

**Spec:** `docs/superpowers/specs/2026-10-28-npx-stdio-design.md`

## Global Constraints

- Tên package `lta-redmine-mcp`, license MIT, `bin: { "lta-redmine-mcp": "dist/main.js" }`, `files: ["dist"]`.
- Transport: `http` nếu argv có `--http` hoặc `MCP_TRANSPORT=http`; mặc định `stdio`. Giá trị `MCP_TRANSPORT` khác `stdio`/`http` (sau trim, không phân biệt hoa thường) ⇒ lỗi.
- Stdio thiếu `REDMINE_API_KEY` ⇒ lỗi đúng chữ `REDMINE_API_KEY is required in stdio mode`. `PORT` chỉ validate khi http.
- Stdio: stdout chỉ cho JSON-RPC. Nest logger `['error']` (Nest 11 chỉ ghi `error` ra stderr; `warn`/`log` ra stdout).
- Không log API key. `RedmineGateway` / `ProjectAccessPolicy` không đổi.
- Lỗi config khi khởi động ⇒ message ra stderr, `process.exit(1)`.

## Review Focus

1. Mặc định đổi sang stdio làm vỡ HTTP: `ConfigModule` đọc `process.argv`; spec controller (chạy dưới jest, không `--http`, không key) sẽ lỗi khi khởi tạo. ⇒ Task 1 đặt `MCP_TRANSPORT=http` trong `mcp.controller.spec.ts`, và test `http không cần key`.
2. `REDMINE_API_KEY` chỉ có khoảng trắng ⇒ coi như thiếu. Test ở Task 1.
3. `MCP_TRANSPORT=HTTP` / `' http '` ⇒ http. Test ở Task 1.
4. Thiếu key khi chạy thật ⇒ exit code 1, message trên stderr, stdout rỗng. Test e2e ở Task 3.
5. Log lọt ra stdout làm hỏng protocol ⇒ test e2e `listTools()` ở Task 3 (client parse stdout).

### Task 1: Config — transport + apiKey

**Files:**
- Modify: `src/config/config.ts`, `src/config/config.module.ts`, `src/mcp/mcp.controller.spec.ts` (beforeAll)
- Test: `src/config/config.spec.ts`

**Interfaces:**
- Produces: `AppConfig` thêm `transport: 'stdio' | 'http'` và `apiKey?: string`; `parseConfig(env: NodeJS.ProcessEnv, argv: string[] = []): AppConfig`.

- [ ] **Step 1: Sửa test cũ + viết test mới.** `base` thành `{ REDMINE_URL: 'https://rm.example.com', MCP_TRANSPORT: 'http' }`; hai test `toEqual` cũ thêm `transport: 'http', apiKey: undefined`. Test mới (dùng `url = { REDMINE_URL: 'https://rm.example.com' }`):

```ts
it('defaults to stdio and reads the key', () => {
  expect(parseConfig({ ...url, REDMINE_API_KEY: ' k ' })).toMatchObject({ transport: 'stdio', apiKey: 'k' });
});
it.each([[{}, ['--http']], [{ MCP_TRANSPORT: 'http' }, []], [{ MCP_TRANSPORT: ' HTTP ' }, []]])(
  'http via %p %p', (env, argv) => {
    expect(parseConfig({ ...url, ...env }, argv).transport).toBe('http');
  });
it('http does not need a key', () => {
  expect(parseConfig(url, ['--http']).apiKey).toBeUndefined();
});
it.each([undefined, '', '   '])('stdio rejects REDMINE_API_KEY=%p', (k) => {
  expect(() => parseConfig({ ...url, REDMINE_API_KEY: k })).toThrow('REDMINE_API_KEY is required in stdio mode');
});
it('rejects unknown MCP_TRANSPORT', () => {
  expect(() => parseConfig({ ...url, MCP_TRANSPORT: 'sse' }, ['--http'])).toThrow(/MCP_TRANSPORT/);
});
it('stdio ignores invalid PORT', () => {
  expect(() => parseConfig({ ...url, REDMINE_API_KEY: 'k', PORT: 'abc' })).not.toThrow();
});
```

- [ ] **Step 2:** `npx jest src/config` ⇒ FAIL (transport chưa có).
- [ ] **Step 3: Implement.** Trong `parseConfig`: đọc `MCP_TRANSPORT` (trim, lowercase, rỗng = `stdio`), validate thuộc `stdio`/`http` (dùng mảng `includes`, không lookup object — xem mistakes log); `--http` trong argv ép `http`. Stdio: `apiKey = env.REDMINE_API_KEY?.trim()`, rỗng ⇒ throw. `PORT` chỉ validate khi http; ở stdio `port` luôn là `3000` (không dùng tới). `MCP_TRANSPORT` được validate cả khi có `--http`. Giữ thứ tự: kiểm `REDMINE_URL` trước. `config.module.ts`: `parseConfig(process.env, process.argv.slice(2))`. `mcp.controller.spec.ts` beforeAll: thêm `process.env.MCP_TRANSPORT = 'http';`.
- [ ] **Step 4:** `npm test` ⇒ toàn bộ PASS; `npx tsc --noEmit` sạch.
- [ ] **Step 5: Commit** `feat: select transport (stdio default) and read REDMINE_API_KEY`.
